# Portfolio Personal — Front End

Frontend del **Proyecto Final Integrador de Argentina Programa 4ta Edición (#YoProgramo)**.

Este proyecto fue desarrollado durante mi formación en desarrollo web Full Stack entre **2022 y 2023**, utilizando Angular para construir la interfaz de un portfolio personal conectado a una API REST desarrollada con Java y Spring Boot.

## 📌 Sobre el proyecto

El portfolio permite mostrar información personal, estudios, experiencia, habilidades y proyectos.

Además de la parte pública, cuenta con un sistema de autenticación que permite acceder a una sección de administración desde la cual se puede gestionar el contenido mediante operaciones **CRUD**.

El proyecto fue desarrollado como parte de las consignas del Proyecto Final Integrador de Argentina Programa y representa mi primera experiencia construyendo una aplicación Full Stack completa.

## 🚀 Tecnologías utilizadas

### Frontend

* Angular 15
* TypeScript
* Bootstrap 5
* HTML5
* CSS3

### Servicios y deploy

* Firebase Hosting
* API REST desarrollada con Java y Spring Boot
* Base de datos MySQL

## 🧩 Funcionalidades

* Portfolio personal responsive.
* Secciones de presentación, estudios, experiencia, habilidades y proyectos.
* Sistema de inicio de sesión.
* Autenticación mediante token JWT.
* Acceso restringido a las funciones de administración.
* Operaciones CRUD para gestionar la información del portfolio.
* Consumo de una API REST mediante servicios de Angular.
* Integración con una base de datos MySQL a través del backend.
* Deploy del frontend mediante Firebase Hosting.

## 📂 Estructura principal

```text
    ├── app.component.ts

```
